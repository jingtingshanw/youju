# 批量取数（harvest）

解决一件事：**把库一次性铺满**。

`scripts/catalog/` 是「用户问一个方向，我现查」；这里是「先把地基打好」。
两者共用 `data/catalog.db` 和 `CatalogItem` 模型。

## 十一个脚本

| 脚本 | 干什么 | 命令 |
|---|---|---|
| `gov_full.py` | 国家级全文：枚举 gov.cn 政策库全部清单，逐份抓正文 | `--list` / `--fetch` / `--stats` |
| `meta.py` | 抽 gov.cn 元信息，重点是**时效**（已失效 / 已修改 / 有效） | `--limit N` / `--stats` |
| `city_registry.py` | 生成「城市名 → 政府门户域名」对照表 | 无参数 |
| `local_catalog.py` | 省 / 市 / 县三级目录：探入口 → 翻栏目 → 落库 | `--run --level 省/市/县` |
| `scan_saas.py` | 扫失败站里有多少用 `p.so-gov.cn` 那套政务 SaaS | 无参数 |
| `scan_was5.py` | 扫失败站里有没有能用的 TRS WAS5 检索服务（**含实测**） | 无参数 |
| `build_index.py` | 全文切块 + SQLite FTS5 索引（中文 2-gram） | `--limit N` / `--search 词` |
| `export_catalog.py` | 地方目录导出 CSV + 覆盖报告 | 无参数 / `--level 市` |
| `npc_laws.py` | 解析人大网《现行有效法律目录》PDF → CSV + 入库（法律层） | `--stats` |
| `report.py` | 一句话回答「库里有什么」 | 无参数 |
| `diag_*.py` | 单站诊断：列表结构 / 翻页机制 / 受阻原因 / 批量 | `--only 站名` |

两个 `scan_*` 是"先探路再决定要不要写适配器"用的。它们只读不写，跑一轮
不到两分钟，作用是**在投入 20–40 分钟逐个适配之前，先知道值不值得**。
`diag_*` 是反过来用的：**已经决定要攻某个站了，先看它到底卡在哪一步**。

`local_catalog.py` 常用开关：`--only 站名1,站名2` 单站复验、`--retry-failed`
只重跑上一轮失败的站、`--only-ok` 只深翻已能抓的站、`--pages` 翻页深度、
`--cols` 子栏目展开数、`--probe` 只看不落库。

## 地方目录怎么抓：三条路并联

地方 2,491 个门户干的是同一件事——首页有个「政策文件 / 文件库」入口，点进去是
一列标题。但列表怎么装进页面，三种做法各占一批，所以探测器同时试三条路，
按「一次能拿多少」排序：

| 路 | 长什么样 | 典型站 | 为什么有效 |
|---|---|---|---|
| 全量 JSON | 栏目页里嵌着 `…-articleList.json`，一个文件就是该栏目全部条目 | 江西 | 一次请求拿全，没有分页状态可丢 |
| jpage 数据源 | 页面里藏 `dataproxy.jsp?page=N`，返回带 `totalrecord` 的 XML | 江苏、安徽 | 源端自报总数，知道该翻多深 |
| 静态列表 | 标题直接写在 `<a>` 里，翻页靠「下一页」或模板推 | 浙江、北京、鹰潭 | 最简单，覆盖最广 |
| WAS5 检索 | `/was5/web/search?channelid=N&templet=docs.jsp&searchword=&page=&perpage=` 直接返回 JSON | 福建 | 自带 `fileno` 发文字号，一页 100 条，可翻 500 页以上 |
| POST 接口 | 逐个从站点自己的 JS bundle 里挖出来的 JSON 接口 | 上海 | 一次能拿上万条，但一站一适配 |

入口识别同时看**文字**和 **URL 路径**：文字可以是任何写法（福建写「政策文件库」、
湖南写「文件库」、上海写「政策发布」），但 `/zhengce`、`/zcwj`、`/wjk`、`/zck`
这些路径是老惯例，改版也不常动。两个信号都算分，避免单看一个漏掉一半。

**WAS5 那条路的用法**：它本质上是个全文检索服务，不是列表。所以不能空着手
翻页——先按**文号前缀**分片（福建用「闽政」「闽政办」「福建省人民政府令」），
每片单独翻到底再合并。文号前缀是最好的分片键：既覆盖全，又天然只命中红头文件。
`channelid` 只能从站点自己页面里的 `<input name="channelid" value="N">` 取，
猜不出来；而且**识别到不等于能用**——青海识别出了 `219598`，但那个服务对匿名
请求回的是 TRS 错误页而不是 JSON。

## 三层东西，别混

```
data/fulltext/<xx>/<key>.txt   全文正文，18,608 份，逐份可追到 URL
data/catalog.db  .fulltext      全文索引表（路径、字数、状态、失败原因）
data/catalog.db  .doc_meta      元信息与时效（索引号/成文日期/时效原文/效力档）
data/catalog.db  .items         目录：名称/文号/发文机关/发布日期/链接
data/catalog.db  .local_site    每个站抓没抓到、为什么
data/kb.db                      检索索引（blocks + FTS5），167,595 块
```

**全文和目录是两层不同可信度的东西。** 全文是抓到的原文，能引用；目录只有
「这份文件存在」这件事，正文没抓，引用前必须回源。

**时效是第三层，也是最容易被忽略的一层。** 库里有 3,849 份 2016 年前的文件，
抽查 30 份最老的文件，13 份页面明确写着「已宣布失效」。拿失效条文去核验，
结论是反的：工具说「有依据」，而那份依据二十年前就作废了。`doc_meta.eff_status`
分四档 **valid / amended / repealed / unknown**——没有时效字段的一律 unknown，
不默认有效。

## 实测数字（2026-10-20）

- gov.cn 政策库清单：**18,916 条**（国务院 6,219 + 部门 12,697）。源端自报
  6,222 + 12,806 = 19,028，差额 112 条（0.6%）是翻页期间新文件插入造成的偏移，
  重跑一轮 `--list` 会自动去重合并。
- 全文：**18,608 份成功 / 7,291 万字**。首轮 402 份失败，修完两批提取 bug 后
  94 份恢复，**308 份仍失败**——抽样 60 份全部是「页面能打开、正文不在 HTML 里」
  （1980—1990 年代老文件，源端只提供扫描件），页面上只剩元信息和时效。
- 索引：**167,595 块 / 980 MB**，平均 9 块/份，建库 1 分钟。
- 单份正文抓取 0.2–0.3 秒，4 线程 6.6 条/秒，18,900 份约 47 分钟。
- 站点清单：省级 31、市/州/盟 685、区/县/旗 1,775，合计 2,491 个政府门户。
- **地方目录：65,111 条**（省级 15,864 / 市级 16,303 / 县级 32,614 / 国家名录 330），
  覆盖 1,491 个地域。导出在 `data/catalog/export/`。
- **法律层：308 条**（全国人大《现行有效法律目录》，2026-08-28 版）。
  只有名称 + 法律沿革，没有条文——它是「这部法还在不在」的判据，不是引用源。
- 站点可抓率（纯 HTTP + 正则 + 接口发现，不渲染 JS）：省级 **21/31**、
  市级 **409/685**、县级 **1,115/1,775**，合计 1,545/2,491 = **62%**。
- 上海一家贡献 10,235 条——它是 Vue 应用，通用探测器完全抓不到，是单独挖出
  `POST /gwk/policy/page` 接口后一次拿全的（源端自报 10,608）。
- 福建 2,838 条——政策文件库同样是 Vue 应用，但底层是 TRS WAS5，按文号前缀
  分片（`闽政` 7,571 → `闽政办` 2,846 → `人民政府令`）翻页取全，147 秒。
- 目录里**约 5.2%（3,558 条）是人事任免、表彰、提案答复函**这类「有文号但不是
  政策」的条目，已按标题词表统一剔除。这个过滤放在 `save()` 一处，所有抓取路线
  都走它，避免每加一条路线就漏一次。
- 条目分布高度不均：上海 10,235、福建 2,838、江苏 1,691、昭通 1,331，往下迅速
  掉到几百、几十。这反映的是**站点归档习惯**，不是地方文件数量——有的市把 2000
  年以来的文件全放在线上，有的市只在栏目里挂最近 20 条。

## 踩过的坑（都在代码注释里留了痕）

1. **`t` 参数是废的，只有 `type` 有用。** 传 `t=zhengcelibrary_bmgz` 仍然返回
   部门库那 12,806 条——所谓「部门规章库」在这套接口里不存在，它的内容已经在
   `bwyzcwjk` 里。
2. **老页面的正文不到 800 字符时会被截成 34 字。** 短批复（如「同意某开发区
   更名的批复」）正文本来就只有一百来字，`_cut_tail` 从第 800 字符开始找结尾，
   直接把它砍没了，而且长得像「抓取成功」。
3. **中文占比 0.25 的线太高。** 《国务院关于同意在深圳市暂时调整实施有关行政
   法规规定的批复》有 8,000 字正文，中文占比只有 0.21（大量条款编号、表格），
   被判成垃圾。降到 0.12。
4. **分页不是 `index_2.html`。** 大汉版通是 `index.html → index_1.html`；
   江苏这类「jpage」站是 `dataproxy.jsp?page=N`，返回带 `totalrecord` 的 XML——
   那个数是「这个栏目一共多少份文件」，比翻页猜深。
5. **两个进程同时写 SQLite 会直接死。** 全文抓取和目录抓取并行跑，后启动的
   抛 `database is locked` 退出。连接已改成 `timeout=60` + WAL + `busy_timeout`，
   但**写与写仍然互斥**，跑批量任务时一次只开一个写进程。
6. **中文 2 字词必须能查。** FTS5 的 trigram 要求查询 ≥3 字符，「征收」「补偿」
   这类两字词直接失效。所以自己切 2-gram（文本 → 「征收 收补 补偿」），
   查询侧同样切，用 unicode61 索引。
7. **Word 导出的 `<td>` 标签能到上千字符。** 正则 `<[^>]{1,400}>` 剥不掉超长标签，
   几万字 CSS 样式文本漏进正文。《国务院关于开展营商环境创新试点工作的意见》
   因此中文占比掉到 0.08 被判失败。改成 `<[a-zA-Z/!][^<>]*>`（不限长、不跨标签）
   并先剥 `style`/`class` 属性，同一份文件从 34 字回到 **21,440 字**。
8. **正文窗口不能写死。** 原来从容器起点切 40 万字符，而 gov.cn 老页面整体
   44.8 万字符、结尾锚点在第 43.6 万处——锚点在窗口外，等于没找，整段返回来。
9. **精确容器不要做密度校验。** `id="UCAP-CONTENT"` 这类特征已经足够精确，
   再要求「容器后 4000 字符内有 80 个中文字」会误杀 Word 页面：每个字包在几百
   字符的 `<span style>` 里，4000 字符只够装标题。314 份失败里一半是这么来的。
10. **错误信息要能读。** 404 响应的 body 也可能是 gzip，不解压就 decode，
    日志里是 `HTTP 404 \x1f\x8b\x08...` 乱码，没法判断是真 404 还是被 CDN 拦了。
11. **`title=""` 会把整条标题吞掉。** `_anchors` 原来是「有 title 就用 title，
    否则用正文」，可空字符串也算「有」。绍兴嵊州的政策文件栏目 97 个站内链接，
    标题长度全部为 0，漏斗在「长度≥8」这一步归零，整站被判成「入口在但解析不出」。
    空 title 在很多模板里是常态。改成「title 非空才用，否则回落到正文」。
12. **只认 `.html` / `.shtml` 结尾，把一半站点的详情页排除了。** 塔城地区是
    `/zfxxgk/zc/gfxwj/…`、淮南市是 `/public/column/6596035?catId=…`，都没有后缀。
    改成「排除静态资源，然后有页面后缀 或 路径里带 4 位以上数字 ID」。
13. **「政府公报」不能和政策文件库同权重。** 它曾经和一级词混在一个词表里，
    还因为 URL 含 `zfgb` / `gongbao` 额外加分，结果在地市站上把「政策文件库」
    挤掉了——邢台、铜川、东营、开封、河池、呼和浩特抓到的全是公报页。公报页上
    是「2026 年第 3 期」这种期号列表，不是文件列表。现在公报单独成档，只做兜底。
14. **翻页会自环。** `find_next` 在 `index.html`（页码 0）时按模板推出下一页，
    写成了 `"index.html" if cur_no == 0 else …`，于是「下一页」永远翻回自己。
    浙江 20 页只拿到 38 条，原因是 20 次抓的都是首页。首页的下一页是
    `index_2.html`（大汉版通；注意有站点是 `index_1.html`，两者都要试）。
15. **列表在 iframe 里 / 页面是 meta refresh 空壳。** 山东「省政府及省政府办公厅
    文件」外层只有 11 个导航链接，列表在 iframe；陕西「省政府文件」返回 311 字符
    的 `<meta http-equiv="Refresh" content="0;URL=./zfl/">`。前者要跟 iframe src，
    后者要跟跳转——都不是 SPA，只是多一层壳。
16. **超时值要按批量规模定。** 写死 60 秒是因为江苏的 dataproxy 单页要 19.8 秒；
    但县级 1,775 个站里几百个不响应，60 秒一个就能把整轮拖到几小时。改成默认 20 秒，
    需要长等的只有 jpage，那一处单独传 60。
17. **翻页要有早停。** 分页参数无效时每页都返回首页内容，深翻 10 页等于在同一页
    上请求 10 次。改成「这一页没有新条目就收手」，jpage 是「连续两页没有新条目」。

## 一轮完整的跑法

```bash
# 1. 国家级清单（约 10 分钟，可断点续跑）
python scripts/harvest/gov_full.py --list

# 2. 国家级全文（约 50 分钟，可断点续跑）
python scripts/harvest/gov_full.py --fetch --workers 4

# 3. 元信息与时效（约 45 分钟，可断点续跑）
python scripts/harvest/meta.py --workers 4

# 4. 站点域名表（约 1 分钟）
python scripts/harvest/city_registry.py

# 5. 省市县目录（单进程跑，别和 2、3 并行）
python scripts/harvest/local_catalog.py --run --level 省 --pages 20 --workers 4
python scripts/harvest/local_catalog.py --run --level 市 --pages 3 --workers 6 --skip-done
python scripts/harvest/local_catalog.py --run --level 县 --pages 2 --workers 6 --skip-done

# 6. 建索引
python scripts/harvest/build_index.py

# 7. 看现状 / 试查
python scripts/harvest/report.py
python scripts/harvest/meta.py --stats
python scripts/harvest/build_index.py --search "历史建筑 修缮"
```

## 还没解决的

- **946 个站抓不到，根本原因是列表不在 HTML 里。** 省级 10、市级 276、
  县级 660。三类：① 前端渲染（Vue/React 应用壳，HTML 里一条都没有）；
  ② 反爬（湖北、甘肃返回 412，青海隧道连不上）；③ 首页真的没有文件栏目入口
  （绥化、伊春、大兴安岭那一片）。
  **不要对这批上 playwright。** 三种病里渲染只治第一种，而 2,491 站 × 3 页 ×
  4 秒 = 8.3 小时，模板一改全废。已验证的出路是逐个挖数据接口——上海就是这么做
  成的（10,235 条），但每个站的 body 参数名都不一样，一个站 20–40 分钟。
- **`p.so-gov.cn` 那套政务 SaaS 试过，天花板很低。** 全量扫了 946 个失败站，
  只有 3 个用这套（福建、榆林市、临沂市河东区）。接口是
  `POST https://api.so-gov.cn/query/s`，`qt=*` 可以枚举，但：
  `pageSize` 被服务端钉死在 20（传 100 也是 20）；翻到约 30 页后**静默重置回
  第 1 页**（`page=50` 和 `page=1` 返回同一批）；`startDateStr` / `C1` 这些
  筛选参数只改 `totalHits` 不改结果集。所以单查询最多拿 600 条，做不成目录。
  **真正好用的是它底下的 TRS WAS5**——福建就是绕到那一层才拿到 2,838 条。
- **WAS5 也没能覆盖剩下的站。** 同样扫了 946 个失败站，逐个找
  `<input name="channelid">` 并实测接口：**可用 0 个**。识别出 channelid 的只有
  青海，而它的 WAS5 对匿名请求回 TRS 错误页。结论是这批站要么已经现代化（SPA），
  要么老 TRS 的检索服务没对公网开放——不是"再试一次就能通"的问题。
- **法律层只解决了"有没有"，没解决"怎么写的"。** 《城乡规划法》《建筑法》
  这些法律**本体仍不在库里**。gov.cn 政策库只收国务院和部门文件，不收人大立法
  （实测搜"中华人民共和国城乡规划法"，返回的全是标题里带"规划"或"法"的其他
  文件）。权威源 `flk.npc.gov.cn` 换成了 Vite 单页应用，接口
  `/law-search/search/list` 的参数结构藏在不透明的 body 里，而且整个
  `/law-search/` 前缀被 CWAP WAF 拦着——带 cookie 会话重试仍然 307 到自身，
  需要执行 JS 拿 `wzws_sessionid`。零依赖拿不下来。
  现在拿到的是 `www.npc.gov.cn` 首页挂的《现行有效法律目录》PDF：308 条，
  名称 + 法律沿革（哪年通过、哪年修正过几次），**没有条文**。
  想引用法条原文，下一步得用 pypdf 之外的办法解 PDF（人大网的单个法条页是
  静态 HTML，但入口散在 `/npc/c2/…` 下的栏目树里，没做）。
- **目录条目只有标题和日期。** 要引用必须回源抓正文，这一步目前靠
  `gov_full.py` 那条链路，地方站还没接进来。
- **地方站转载中央文件会被标成本地。** 地域取的是「来源站点」，所以张家口宣化区
  转载的《城市更新"十五五"规划》在目录里属于宣化区。做效力和适用范围判断时要
  注意这一层。
- **308 份老文件的正文是扫描件。** 页面上的附件多是 .pdf / .doc，零依赖解析
  只能读 .docx，所以这批暂时拿不到正文，只拿到元信息和时效。
