# 有据 · 政策效力核验与可溯源引用引擎

**模型给答案，规则层核对答案。核不过的降级或拒答。**

一个面向规划行业的政策工具。你问一个政策问题，或贴一段稿子：系统从三层数据里找依据，
让模型作答，再用一层**不调用模型**的确定性规则逐条核对——条号是否越界、引文是否真实、
法规是否失效、名称是否错配、所问法规划界。核不过就不给结论，或者降级成「部分作答」。

它存在的理由只有一句：**编造的条号和真实的条号，在界面上长得一模一样。**

## 六十秒

**先开产品入口**（这就是你问的「一个能用的东西」）：

```bash
python app/server.py          # → http://127.0.0.1:8848
```

零依赖，只用标准库。一次请求跑两条链路——左边「过去的做法」（朴素检索 + 无约束提示词 +
不核验），右边「有据」（三路召回 + 强约束 + 五项核验 + 逐句回查）。同一个模型、同一份库、
同一个核验器，所以右边抓出来的问题，就是左边在真实使用中不会告诉你的部分。

**其它入口**：

```bash
python mvp/server.py          # 完整 MVP（三层面板 + 目录检索），8765 端口
python scripts/eval_retrieval.py          # 检索对比：基线 vs 三路召回
python scripts/build_ledger.py --report   # 时效台账统计
python scripts/probe_batch.py             # 五道题跑完整链路，出实测记录
python scripts/make_release.py            # 打发布包（代码包 + 数据包 + RELEASE.md）
```

模型 key 从 `.env` 读（项目根 / 上一级 / 上两级，谁先存在用谁），
`DASHSCOPE` / `DEEPSEEK` / `ARK` 任一能跑就行。开关 `PV_TOKEN` / `PV_PORT` /
`PV_BIND` / `QW_RAW_ONLY` 也认 `.env`。

**起之前先自检**（30 项，不联网不调模型，2 秒）：

```bash
python scripts/selftest.py       # 通过 30/30 才往下走
```

它能挡住的问题都是「不会报错但会让检索少给几条」的那种：索引没重建、台账漏了某个地域、
`docs` 和 `blocks` 对不上。少给几条的后果是「用户以为没有」，这是本项目最不能出的错。

**要从这台机器搬走**：看 `DEPLOY.md`。机器要求、数据打包、systemd、Caddy、回滚、五个已知的坑。

## 三层数据，三个问题

| 层 | 规模 | 回答 | 能不能直接引 |
|---|---:|---|---|
| L0 法律名录 | 308 条 | 这部法还在不在现行名单里 | ❌ 只有名称与沿革 |
| L1 目录层 | 67,541 条，覆盖 1,493 个市/县 | 这个方向有哪些文件 | ❌ 只有标题、文号、日期、链接 |
| L2 全文层 | 34,634 份 / 1.37 亿字 | 这一条具体怎么写的 | ✅ 可逐条引 |
| 核验层 | 178,386 条条文 / 34,634 行台账 | 你引的这一条站不站得住 | ✅ C1–C5 全部回原文核 |

有正文的是 8 个地域口径：国家 18,608 · 上海 8,903 · 福建 2,594 · 江苏 1,585 ·
南京 1,581 · 昭通 1,325 · 平潭 28 · 广州 10。其余 1,400 多个市/县只有目录，正文按需联网取。

**四个数字必须一起看**：站点可抓 62%（1,545/2,491）、地方条目有正文 23.7%
（16,026/67,541，另外 18,608 份是国家级全文，不进目录层）、条级索引 178,386 条、
失效台账 34,634 行。前两个是「抓得到多少」，后两个是「核得动多少」。

台账六态：`no_signal 31,937 · in_force 1,397 · repealed 856 · expired 343 ·
superseded 81 · pending 20`。其中 **`expired` 343 份是最值钱的一列**——它们是
自己到期的（文末写「有效期至 2025-12-31」），没有任何文件宣布它失效，
三态台账里全都躺在「未见废止记录」里，看着像有效的。

## 现在能做什么，不能做什么

**能**

- 按「地域 × 主题」出四级文件清单，并**说清哪一级没抓到、为什么**
- 在 1.86 万份国家级正文里检索，返回条号 + 原文片段 + 文号 + 链接（5–35 ms）
- 对 8 部法规上的问答做五项确定性核验，结论可复现、断网可跑
- 拿到一部法律「还在不在现行名录」的答案（实测《环境保护法》已被《生态环境法典》替代）

**不能**

- 不能引用 65,111 条地方目录里的任何一条正文——它们没有正文，只有元信息
- 不能核验 96% 以上条目的条号与时效——条数表和时效台账还只覆盖 8 部
- 不能给《城乡规划法》等人大立法的条文——法律层只有名录
- 不能覆盖 38% 的政府门户（946 站：前端渲染 / 反爬 / 无入口）
- 不能保证清单完整，也不能把「没抓到」说成「没有」——后者是产品红线

## 一句话

这个项目在证明一件事：**在「容错很低、但使用者自己发现不了错」的场合，
可靠的不是更大的模型，是能说清「我核了什么、没核什么」的规则层。**
库可以慢慢扩，这一层扩不了，扩多少库都白搭。
