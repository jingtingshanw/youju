# 对抗题扩容与阈值结论翻转

日期：2026-10-14　机器：本机（Windows 11）　Dify 0.15.3 / 知识库「政策法规语料库v3」
前置：`research/06-百炼全栈落地与重排实测.md`（结论：rerank 分数可在 L1+L2 与 L4 之间分开一条阈值）

---

## 一、结论先说

**上一轮那条「间隔 0.062，一条阈值能分开」的结论，被本轮实验推翻了。** 不是方法错，是样本不够——扩到 40 道对抗题之后，同一个配置、同一个知识库，对抗题里有一半以上的分数**高于**正确题的最低分。

三条新结论：

1. **对抗题不是一类东西，是两类。** 决定「分数能不能挡住它」的不是「有没有依据」，而是**「问题问的那个话题，在语料里是否真实存在」**：
   - 话题不存在（B 纯外部 / E 主题错位 / 部分 A、G、H）→ 分数低（0.13–0.35），分数挡得住；
   - 话题存在、但具体那条不存在（C 越界条号 / D 节选 / F 时效）→ 分数高（0.45–0.86），**分数完全挡不住**。

2. **阈值只能当兜底，不能当防线。** 阈值 0.50 能挡住 22/40 对抗题、零误杀；但即使把阈值拉到 0.90（会误杀 4/20 正确题，误杀率 20%），也才挡住全部 40 道——代价不可接受。真正的防线只能是**条文级校验**（条号越界 + 引用存在性 + 时效比对）。

3. **重排的定位要再改一次。** 上一轮我写「重排序是本产品的安全阀」。准确的说法是：**重排是「话题级」安全阀，只挡得住「用户问的东西整个不在库里」这一种情况**。而最危险的那一类（C/D/F，用户以为有依据、语料里话题也真在、只是要找的那条不存在），重排一点忙都帮不上。

4. **端到端拒答 39/40**（唯一失守的是 L4-26，见第八节）。但第一遍自动判分给的是 **34/40**——其中**5 道是判分器误报**，而且误报全部发生在分数最高的那几道上。原因见第八节：用「清单是否为空」当「是否拒答」的代理指标，这个代理只对「话题整个不存在」那一类成立。

另外补上了 `eval/README.md` 里记的两个判分盲区。但要说清楚：「引文级比对」在三批数据上**零真阳性**，README 里原先记的那个「已知案例」经复核是我写错的（见第七节）。

## 二、这轮做了什么

| 项 | 内容 |
|---|---|
| 对抗题扩容 | L4 从 4 道 → **40 道**，按 8 类形态各 5 道 |
| 出题断言 | 每道对抗题挂一条**结构断言**，生成时由程序验证题目在结构上真的成立 |
| 判分盲区 | 补「跨法规主体归错检测」与「引文级字符比对」 |
| 评估集分层 | 拆成**能力集**（L1–L3，26 题）与**防火墙集**（L4，40 题）两个用途 |

### 为什么 L4 不再遵守 15% 的占比

原来的设计是 40/25/20/15。扩到 40 道后 L4 会占到 61%，看起来是破坏了分层。

但 L1–L3 和 L4 的用途本来就不同：
- **L1–L3 是能力集**：考「答得对不对」，占比要按业务分布设计（基础事实最多，边界最少）；
- **L4 是防火墙集**：用途是**标定拒答阈值**，需要的是把分数分布打实——每一类形态都要有足够样本，占比由「分布需要」决定，不由「业务频率」决定。

把两者混在一个占比里，会用「业务上少见的题不该多出」这种理由，把标定阈值最需要的样本压掉。所以现在分开成两张表。这一点写进了 `eval/README.md`。

### 8 类对抗形态

| 类 | 形态 | 一句话 | 例 |
|---|---|---|---|
| A | 被引用但库内无全文 | 法规名真实出现在库内（制定依据里），但库里只有名字 | 问《生态环境法典》第 215 条 |
| B | 纯外部法规 | 法规名在库内一次都没出现 | 问《上海市生活垃圾管理条例》 |
| C | 越界条号 | 真法规 + 真主题 + 假条号 | 问《深圳…监察条例》第八十条（仅 66 条） |
| D | 转述性节选 | 库内有片段，但它是嵌在别处的「被调整对象」 | 问《土地管理法》第四十六条第一款原文 |
| E | 主题错位 | 真法规 + 该法规根本不涉及的主题 | 问《深圳…监察条例》里的扬尘规定 |
| F | 时效陷阱 | 问已废止法规「现在怎么执行」 | 「我要依据噪声法处罚企业，引用第几条」 |
| G | 跨层级混淆 | 问国家/省级规定，库内只有市/州级 | 问《风景名胜区条例》对天山天池的要求 |
| H | 虚构制度 | 措辞合法、听起来像法规该有的内容，但库里没这套制度 | 问怀化条例的「扬尘专项资金申请流程」 |

### 结构断言：让「这道题成立」变成可验证的

这是本轮最重要的质量机制。每道 L4 题除了文本，还挂一条断言：

```
law_absent        断言该法规名在语料全文里出现 0 次          → B / G
law_referenced    断言该法规名在语料里出现过（被引用）        → A
art_out_of_range  断言该条号 > 该法规实际条数（真的越界）     → C
topic_absent      断言该主题词在该法规全文里 0 次出现         → E / H
law_expired       断言该法规在时效台账里是废止/失效状态       → F
excerpt_in        断言该节选关键词确实在承载文件里            → D
```

**它立刻就抓到了 3 条我自己写错的题**：

```
[x] L4-36 断言失败：虚构术语『专项资金』在 ['土壤污染防治法'] 中出现，题目不成立
[x] L4-38 断言失败：虚构术语『奖励』在 [5 部法规] 中出现，题目不成立
[x] L4-39 断言失败：虚构术语『门票』在 ['昌吉回族自治州天山天池风景名胜区保护管理条例…'] 中出现
```

后两条尤其说明问题：
- 「奖励」是个太平常的词，拿它当「虚构术语」不成立 → 改成断言该词不在**目标法规**里；
- L4-39 我本以为风景名胜区条例里不会有「门票」，结果它有（第二十一条禁止行为里的「逃票、违规销售门票」）→ 换成更精确的「门票价格」，并把这个一字之差写进了题目备注。

40 道题靠人肉检查，一定会漏。断言让这个失效模式不可用。

## 三、检索层结果：按形态看，分数根本不是一档

同一个知识库（v3，8 篇 / 435 段）、同一套配置（`tongyi/text-embedding-v3` + `tongyi/gte-rerank-v2`），只换评估集。

### 能力集（应该命中）的分数分布

| 层 | n | min | 中位 | max |
|---|---|---|---|---|
| L1 基础 | 12 | 0.904 | 0.941 | 0.949 |
| L2 推理 | 8 | **0.508** | 0.887 | 0.930 |
| L1+L2 | 20 | **0.508** | 0.926 | 0.949 |
| L3 边界 | 6 | 0.366 | 0.690 | 0.954 |

L2-02（怀化「区内/区外处罚主体对比」这道两跳题）= **0.508**，是全部正确题里唯一的低点，第二名（L2-08）就已经是 0.748。**这个 0.508 就是阈值的天花板**——任何高于它的阈值都会误杀这道正确题。

这与 `research/06` 里 B 组的数字完全一致（L2 min 0.509、L3 min 0.366），说明配置没变，两次结果严格可比。**唯一的变量是 L4 的题量从 4 变成 40。**

### 防火墙集的分数分布（按 8 类）

| 类 | 形态 | n | min | 中位 | max |
|---|---|---|---|---|---|
| A | 被引用但无全文 | 5 | 0.161 | 0.196 | **0.727** |
| B | 纯外部法规 | 5 | 0.134 | 0.143 | 0.158 |
| C | 越界条号 | 5 | 0.325 | **0.826** | **0.860** |
| D | 转述性节选 | 5 | 0.447 | 0.663 | **0.842** |
| E | 主题错位 | 5 | 0.230 | 0.330 | **0.707** |
| F | 时效陷阱 | 5 | 0.420 | 0.599 | **0.749** |
| G | 跨层级混淆 | 5 | 0.169 | 0.239 | **0.826** |
| H | 虚构制度 | 5 | 0.349 | 0.528 | **0.822** |

一眼能看出两组：

- **B 类整齐地落在 0.134–0.158**，全部低于正确题的最低分。这是唯一一类「分数挡得住」的干净形态。
- **C 类有三道超过 0.82**（深圳第八十条 0.860、呼伦贝尔第六十条 0.832、葫芦岛第六十条 0.826）——**比 25%–35% 的正确题还高**。

C 类为什么高？因为**题目问的话题，在语料里真实存在**：

```
L4-12  《深圳…监察条例》第八十条关于「强制拆除违法建筑」的程序
       → 「强制拆除」本来就是深圳条例的核心内容，检索当然给高分（0.860）
L4-15  《呼伦贝尔…条例》第六十条规定的「清雪时限」
       → 清雪时限真实存在于第三十九条（L1-12 就是问它），top1 = 0.832
```

**条号是假的，话题是真的。** 检索器和重排模型都只看「这段文字和你问的问题像不像」，它没有任何办法知道这个条号越界了。

## 四、阈值扫描：不存在能用的直线

以 L1+L2（n=20）作「正确题」，扫描阈值：

| 阈值 | 对抗题被挡住 | 正确题被误杀 |
|---|---|---|
| 0.20 | 10/40 | 0/20 |
| 0.30 | 13/40 | 0/20 |
| **0.40** | **19/40** | **0/20** |
| 0.50 | 22/40 | 0/20 |
| 0.60 | 26/40 | 1/20 |
| 0.70 | 28/40 | 1/20 |
| 0.80 | 34/40 | 2/20 |
| 0.85 | 39/40 | 4/20 |
| 0.90 | 40/40 | 4/20 |

读法：

- **想零误杀**，阈值最高只能到 0.50，此时只挡住 22/40——**剩下 18 道（45%）对抗题照样穿透**；
- **想全挡住**，阈值要拉到 0.90，代价是 20% 的正确题被判「检索不到」。

而且**在 0.83–0.86 这个区间，对抗题和正确题完全交错**：L4-12 的 0.860 > L2-03 的 0.835、L2-07 的 0.846。这一段里没有任何阈值是有意义的。

> **上一轮的「间隔 0.062」是怎么来的**：旧的 4 道对抗题恰好是生态环境法典（0.196）、上海（0.134）、怀化第四十条（0.325）、土地管理法（0.447）。其中 C、D 两类各一道，而挑中的恰好是这两类里分数最低的那两道。**4 道样本里，没有一道「话题在语料里真实存在且高频」的对抗题**——所以量出来的 max 是 0.447。
>
> 这不是「结论错了」，是**在那个样本上，那个结论成立**。这正好印证了当时自己写下的那句「不足以宣称 0.48 是工业级阈值」。

## 五、新的分类学：两类对抗，两种防线

把 40 道对抗题按「话题在语料里是否存在」重排，规律非常干净：

| | 话题级不存在 | 话题存在，具体条文不存在 |
|---|---|---|
| 包含 | B 纯外部、E 主题错位、A/G/H 的一部分 | C 越界条号、D 节选、F 时效 |
| 分数区间 | 0.13–0.35（少数 0.7+，见下） | 0.42–0.86 |
| 分数能挡吗 | **能** | **不能** |
| 唯一有效防线 | 检索分数 + 拒答 | **条文级存在性校验** |
| 用户感受 | 「这个库里没有」 | 「有答案，能引用」——**最危险** |

「话题存在」这一类之所以危险，是因为它从用户视角看**和正常问题一模一样**：法规名真、主题真、条号格式真。用户拿到答案时毫无察觉。

### 少数例外的含义

两类里都有反例，值得单独记：

- **A 类的 L4-05（城市市容和环境卫生管理条例）= 0.727**：话题（户外广告设置）在库内呼伦贝尔条例里真实存在，所以分数高。它是「话题存在」那一类，只是被归在 A。
- **G 类的 L4-33（广东省城乡规划条例）= 0.826**、**H 类的 L4-40（清雪保证金）= 0.822**：同理——「规划土地监察」和「清雪」都是库内真实话题，只是加了一个不存在的层级/制度。

**这三个反例说明：分类的判据不是「我给它起了什么名字」，而是「这个话题在语料里有没有对应的段落」。** 8 类形态是出题视角的分类，两类对抗是**机制视角**的分类，两者交叉但不重合。定产品规则要用后者。

## 六、产品含义：两道独立的闸门

```
用户提问
  │
  ├─ 闸门 1（话题级）· rerank 分数
  │     分数 < 0.40 → 判定「库里没有这个话题」→ 直接告知检索不到
  │     覆盖：19/40 对抗题（B 类全部 + E/G/H/A 的一部分）· 零误杀
  │     挡不住：C / D / F 以及 A/G/H 里「话题真实存在」的那些
  │
  └─ 闸门 2（条文级）· 结构化校验
        · 条号越界：引用的条号 > 该法规实际条数 → 拒绝
        · 引用存在性：引用的 (法规, 条号) 能否在本次召回段落里反查到 → 拒绝
        · 时效比对：引用文件在台账里已废止/失效 → 标注历史参考
        覆盖：C / D / F（15 道 = 37.5%，且全是最危险的那一类）
```

**闸门 2 才是主防线。** 它不依赖任何概率模型，是确定性的规则，可以写进 SLA。闸门 1 是兜底。

这与 `research/06` 的结论有一处修正：

> 上一轮写「重排序是本产品的安全阀，不是优化项」。现在要补一句：**它只是「话题级」安全阀。** 真正拦住「真法规 + 真主题 + 假条号」这种组合的，是条号越界校验——而这件事**根本不需要 rerank**，用一张条数表就够了。
>
> 所以第 6 步（重排序）的价值要重新表述：它是**两条闸门中的一条，且不是主防线**。主防线是结构化的引用校验，成本更低、确定性更强。

### 阈值怎么设

- **方向只能用在上限**：只把「分数低于 X」判为「检索不到」，不用「分数高于 X」判为「有依据」。
- **取值建议 0.40**：在 n=20 上零误杀，且离最近的正确题（0.508）留 0.108 余量。
- **不要设「中间带」的下沿**：`research/06` 里提的「中间带 → 标注依据弱建议复核」这次没有验证——因为对抗题在中间带里的分布（0.40–0.86）和正确题完全重叠，划不出一个能用的中间带。**这条待验证，暂不进产品。**

## 七、判分盲区的修复

`eval/README.md` 里记了两个盲区，这轮都补上了。

### 盲区一 · 跨法规主体归错 → 已补，进硬指标

原判据「条号是否出现在任意召回段落里」抓不到 L2-02：它正文写了「本次检索结果中另有第四十七条第（四）项」，怀化只有 34 条——但「第四十七条」确实出现在同批召回的**呼伦贝尔**段落里。

新逻辑（`prose_cross_doc`）：逐行扫描，维护「当前讨论主体」= 最近一个只含唯一法规名的行；某行的条号不在当前主体的召回段落里、却存在于**别的**法规段落里 → 记一条「跨法规挪用」。

最后那个条件（必须能在别的法规里找到）是刻意的：它把「主体归错」和「条号根本不存在」分开，后者归原有的 `prose_unbacked` 管，两件事不重叠、不重复计数。

### 盲区二 · 引文级字符比对 → 已补，只报告不判罚

原判据只保证「法规 + 条号存在」，不保证「引述的文字与原文一致」。

新逻辑（`quote_unbacked_check`）：从「【《法规》第X条】原文关键句……」的依据行里取引述片段，去掉标点后在召回段落里找。

**第一版误报率 53%**——根因是我的正则把格式模板词「原文关键句」当成了原文，取出来的前 12 个字是「原文关键句工程施工单位…」，永远匹配不上。剥掉模板词后：

```
引文存疑（1 条 · 报告性指标，不计入判罚，供人工复核）：
  L3-06  ['对夜间的定义为晚上十点至次日早晨六点之间的期间设']
```

**剩下唯一的一条，正是 `eval/README.md` 里手写记录的那个案例**：L3-06 登记的是真实存在的第四十三条，但引述的文字（噪声法附则里的"夜间"定义）超出了该条原文。这个洞第一次跑就被自动抓到了。

**为什么只报告不判罚**：模型合法的概括、省略（「…」）、跨条合并都会触发它。误报会导向去「修」一个不存在的问题——这个坑本轮已经踩过一次（判据词命中率在 L3/L4 上系统性骗人，最后改成只在 L1+L2 统计）。所以它作为人工复核的线索，不进 `hard_fab`。

| L4-12 深圳第八十条 | 0.860 | 未拒答 | **正确**：明说「没有第八十条」「无法确认是否存在」 |
| L4-27 土壤法替代条款 | 0.731 | 未拒答 | **正确**：结论直接写「无法回答」 |
| L4-28 海南征收批准 | 0.749 | 未拒答 | **正确**：说明授权期规则 +「现已恢复国务院批准」 |
| L4-37 绿色账户 | 0.528 | 未拒答 | **正确**：「没有关于绿色账户积分兑换制度的条文」 |
| L4-26 噪声法处罚条号 | 0.595 | 未拒答 | **真失守**：明知已废止，仍给出「应引用第七十七条」 |

**这是第二次踩同一个坑。**

- 第一次：用「扫正文正则」判断「挂错法规」→ 4 条正确拒答里 3 条误报 → 改成【引用清单】；
- 第二次：用「清单是否为空」判断「是否拒答」→ 6 条里 5 条误报。

根因相同：**拿一个不区分题型的代理指标，代替语义判断。**

「清单为空」只对 B/E/H（话题整个不存在）成立。对 A/C/D/F/G，正确答案本来就是「指出问题 + 可能给出部分可用依据」——**清单不该为空**。

修法：拒答判据改为「清单为空 **或** 回答里出现负面边界声明」，并且只在 L4 层统计（L1–L3 的正确答案本来就不是拒答，填出来只会被读成缺陷）。

### 误报为什么集中在那 6 道

它们的分数是 0.528、0.595、0.727、0.731、0.749、0.860——**全部 ≥ 0.528**。因果链很直：

```
话题在语料里真实存在 → 检索给高分 → 模型有大量可引用的内容
  → 它给出一份不算空的引用清单（同时明确声明问题不成立）
  → 旧判据看到「清单不空」就判它没拒答
```

**旧判据把回答得最认真的那几道，判成了失败。** 这和第一节的机制发现是同一件事的两面。

### 唯一真失守的那道

L4-26（「我要依据噪声法处罚企业，引用第几条」）：

- 开篇就给了正确的时效提示（「已于 2026-08-15 失效」）；
- 结论里也写了「该法已失效，不宜再作为处罚决定书的依据」；
- **但仍然给出了「处罚决定书应引用的条号」（第七十七条）**，还补了第七十八条的区别。

它的失效模式不是「不知道时效」，而是**没有拒绝用户那个错误的提问假设**。用户已经假定「可以用这部法处罚」，模型顺着这个假定把问题答完了。真实业务里的风险是：用户拿到一份带警告但结构完整的答案，很容易就照着写文书。

**这是本轮唯一需要改产品的问题**，也是「边界声明」和「拒绝作答」必须分开处理的证据——模型做到了前者，没做到后者。

## 九、边界与未解决

1. **阈值 0.40 仍然是「在这个语料、这个题型上」量的。** 语料只有 8 篇、435 段。真实产品面对几百上千部法规时，分数分布会整体位移，0.40 不可迁移。**换语料必须重量。**
2. **L2-02 那道 0.508 是阈值的天花板**，单点依赖。它的分数再低一点，可用阈值还要往下压。
3. **闸门 2 的条数表需要随语料同步。** 本轮已落地为 `data/article_counts.json`（由 `scripts/export_article_counts.py` 从语料导出，8 部法规 50/90/99/34/29/0/66/48 条，自洽校验 0 错误）。但语料一改，这张表必须重新导出——这是新的维护点。
4. **闸门 2 只覆盖「条号级」和「主体级」**，不覆盖「条号对、内容改写了半个字」。
5. **引文级比对这个盲区，实际上没有被验证过。** 三批数据（v1/v4/v5）上零真阳性——而且 `eval/README.md` 上一版记录的那个「已知案例」经复核是我写错的（L3-06 的引述条号与内容全部对得上）。指标保留，但**它在现有语料上没有战绩**，不能当成已验证的能力。
6. **40 道对抗题仍然不是「够」。** 8 类 × 5 道的样本量足够看出「两类对抗」这个结构性差异，但不足以定任何精确阈值。它证明的是「一条线分开」不成立，不是一个新阈值成立。

## 十、待办

1. **给提示词加一个显式的边界判定字段**，例如 `【边界判定】条号越界 / 库内无该法规 / 时效失效 / 无依据`。让判分从「猜」变成「核对」——这和当初用【引用清单】替掉正文正则，是同一个解法。**这是把 L4-26 那类灰区变成可判的前提。**
2. **时效类题的规则要写得更硬**：现在提示词说的是「标注历史参考」，但 L4-26 需要的是「当用户要求你为已废止法规提供可引用条文时，必须拒绝，不得给出条号」。这两条不是一回事。
3. 把「两道闸门」写进产品设计（PRD 的检索章节）：闸门 1 兜底、闸门 2 主防线。
4. 时效台账自动化（`research/06` 待办 2，仍未做）——现在仍硬编码在 `prompts/system-v2.md`。
5. 手册第 6 步的表述再修一次：定位从「安全阀」改为「两条闸门之一，且非主防线」。
